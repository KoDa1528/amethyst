название:
amethyst(аметист)

АМЕТИСТ ЭТО АССЕМБЛЕР С ЧЕЛОВЕСКИМ ЛИЦОМ

девиз аметиста:
no hidden anything
и
one problem - one solution

справка:
аметист довольно хорошо подходит для написания операционных систем и другого системного программного обеспечения
а также ваш код всегда останется таким как вы его написали то есть компилятор не будет менять местами поля в структурах не инициализировать сразу же после того как вы это делает, компилятор будет делать именно то что вы написали
СОВМЕСТИМ С С
а также у аметиста нету стандартной библиотеки всё превращается в чистый ассемблер

примеры:
привет мир:
gem main() -> int do
carve("Hello world!\n")
dig_out 42
end

калькулятор:
gem calculate(int num_f, char sym, int num_s) -> int do
if sym == '+' do
dig_out num_f + num_s
elif sym == '-' do
dig_out num_f - num_s
elif sym == '*' do
dig_out num_f * num_s
elif sym == '/' do
if num_s != 0 do
dig_out num_f / num_s
else
dig_out 404
end
else
dig_out 404
end
end

gem main() -> int do
int a = to(int, ore())
char c = to(char, ore())
int b = to(int, ore())
int res = calculate(a, c, b)
carve("result: ", res, "\n")
dig_out 42
end

работа с mem_alloc:
gem main() -> int do
